# Fonts

Place `inter-var-latin.woff2` here — the Inter variable font, latin subset,
downloaded from https://rsms.me/inter/ (Inter is OFL-licensed; self-hosting is permitted
and required here: no runtime Google Fonts calls from pages that carry PHI).

Referenced by `css/core.css` via a relative URL, so serve this directory
alongside the CSS (Vite: import the woff2 or copy to public/assets).
